# 小说创作者工作台

一个面向长篇小说创作的三栏工作台，从左侧栏的“小说工作台”图标打开。

## 布局

- **左栏 · 作品与目录**：切换作品、新建作品，管理卷与章节树。章节以 Markdown 文件保存在作品目录中。
- **中栏 · 写作区**：编辑、分栏或预览。自动保存、字数统计、章节状态与 `⌘/Ctrl + S` 手动保存。
- **右栏 · 工具区**：出场人物、角色任务、人物八步弧光、地图、事件、人物关系、物品道具、明暗线、伏笔、剧情起伏与钩子。

角色除了当前目标，还可以记录一个终极目标，以及若干条主线/支线短期任务；任务可以关联其他角色，形成 RPG 式的角色任务网。

## 数据与 Git

首次打开时，工作台会在 `~/Documents/DSH小说工作台` 创建一个示例作品《雾港来信》，方便直接体验全部看板。之后新建的作品位于同一作品库下。

每个作品是一个独立目录，也是一条独立的 Git 历史：

```text
~/Documents/DSH小说工作台/
  works/<作品 id>/
    book.json          作品信息
    workbench.json     工具看板数据
    manuscript/        卷目录与 .md 章节
    .git/              该作品的 Git 仓库
```

- 章节内容始终是纯 Markdown 文件，可直接用其他编辑器修改。
- 保存章节会写入 Markdown 文件；Git 面板可查看未提交文件、差异并提交。
- 重命名或移动章节时，工具看板中引用该章节的字段会同步更新；删除章节时，章节元数据会移除，其他看板中指向它的引用会保留，方便你手动处理。删除操作把文件移入作品库的 `.trash` 目录，而不是立即抹除。
- 通过 `DSH_NOVEL_WORKBENCH_ROOT` 环境变量可以改变作品库根目录（需要在启动 DSH 前设置）。

## 使用提示

- 左栏“+”可新建卷或章节；每行悬停后可重命名、上移、下移或删除。
- 写作区右上角可切换“编辑 / 分栏 / 预览”，专注模式会收起两侧栏；编辑器中 Tab 缩进、Shift+Tab 反缩进。
- **预览 AI**：在预览或分栏的预览侧选中一段文字（最多 800 字），会弹出“改写 / 扩写 / 分析 / 后续建议”气泡。点击后调用当前默认模型，并在提示词中带上当前选中段落前后的正文，以及人物、任务、明暗线和伏笔的摘要。结果先在弹窗中预览，确认后再替换选区或插入批注。
- **事件筛选**：按角色名过滤事件，空格分隔多人，可切换“任一 / 全部”。
- **关系筛选**：点击关系图节点高亮该角色的关系；顶部还可按关系类型筛选，两者可以叠加。
- **道具筛选**：按当前持有角色过滤道具。
- **AI 更新看板**：在工具区顶部点击“AI 更新”，选择目标看板，生成增量建议；逐条勾选后应用，未选中的建议不会写入。
- 工具区顶部标签切换看板。多数看板点卡片即可编辑，`+` 新建条目。
- 人物弧光按八步冒险法记录每个角色的阶段状态和笔记。
- 剧情起伏按章节目录顺序绘制张力曲线，拖动滑杆即可记录本章强度。

## 边界

- 这是本地单人工作台，不包含多人协作或云端同步；多设备同步可自行在作品库中使用 Git remote。
- AI 助手使用当前 DSH 默认模型；未配置模型时，预览气泡和看板更新都会提示不可用。
- 工具区顶部的 **AI 更新** 会读取当前章节正文、故事设定摘要和当前看板，生成增量建议。建议以差异列表展示，必须勾选并点击“应用所选”后才会合并；不会自动删除已有条目。
- AI 看板更新覆盖人物、角色任务、弧光、地图地点、事件、关系、道具、明暗线、伏笔、剧情起伏和钩子；一次只更新一个看板，可切换目标看板重新生成。
- Git 面板提供状态、差异、最近历史与提交；不提供分支切换、合并或冲突解决界面。
- 地图是作品内部的节点图，不是地理底图；节点位置会写入 `workbench.json`。
